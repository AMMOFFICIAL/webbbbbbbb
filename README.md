# RedPanel Web

Web statis responsif yang mempertahankan karakter visual hitam-merah dari file Dart yang kamu unggah.

## Menjalankan
- Buka `index.html` langsung di browser untuk preview.
- Untuk menerbitkan ke GitHub Pages: unggah `index.html`, folder `assets/` dan `source_dart/` ke repository, lalu aktifkan Pages dari branch utama/root.

## Penting
Halaman ini merupakan konversi UI web, bukan konversi otomatis semua perilaku Flutter/Dart. Fungsi server (login, admin, domain lookup, Instagram processing) belum dihubungkan ke backend. Tidak ada pengiriman payload gangguan jaringan. File Dart yang tersedia disimpan di `source_dart/` sebagai referensi.
